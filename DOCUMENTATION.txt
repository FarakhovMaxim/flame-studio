FlameStudio

О проекте

Это консольная программа, которая создаёт изображения фрактального пламени. В основе лежит многократное применение математических преобразований к точке. Из полученных точек собирается цветное изображение. Весь расчёт, обработка цвета и сохранение PNG выполняются на Java.

Требования и запуск

Для сборки нужен JDK 17 или новее. Отдельно устанавливать Gradle не нужно, потому что в проекте есть Gradle Wrapper. При первом запуске ему может понадобиться интернет для скачивания Gradle.

В IntelliJ IDEA нужно открыть папку проекта, дождаться импорта Gradle и запустить класс Main или конфигурацию Flame Studio. В консоли появится меню. Номер от 1 до 6 сразу запускает расчёт выбранного пресета. Enter без числа выбирает первый вариант, 0 завершает программу. Ctrl+C останавливает расчёт.

В терминале из папки проекта:
./gradlew --quiet run

В Windows:
gradlew.bat --quiet run

В macOS можно дважды нажать start.command, а в Windows открыть start.bat.

Сборка приложения:
./gradlew build

Запуск собранного JAR:
java -Xmx2g -Dfile.encoding=UTF-8 -jar build/libs/FlameStudio-1.0.0.jar

Результаты

Изображения сохраняются в папку renders. Для каждого PNG создаётся файл properties с параметрами расчёта. Имена содержат название пресета и время создания. Уже существующие файлы не перезаписываются. После расчёта программа пробует открыть PNG в стандартном просмотрщике.

Пресеты

1 — Феникс, золотые и розовые вихри; конфиг phoenix.properties.
2 — Туманность, бирюзовые ленты; конфиг nebula.properties.
3 — Лотос, симметричная фигура с пятью лепестками; конфиг lotus.properties.
4 — Шёлк, фиолетовые складки и нити; конфиг silk.properties.
5 — Коралл, зелёные ветви; конфиг coral.properties.
6 — Галактика, фиолетовые орбиты; конфиг galaxy.properties.

Конфиги находятся в configs. При запуске из корня проекта программа читает их из этой папки. Если JAR запускается из другой папки, используются встроенные конфиги.

Параметры запуска

--preset выбирает пресет по имени: phoenix, nebula, lotus, silk, coral или galaxy.
--config указывает путь к своему файлу properties.
--quality выбирает preview, standard, high или ultra.
--width и --height задают размер от 64 до 7680 пикселей. Общая площадь ограничена 40 миллионами пикселей.
--samples задаёт число итераций от 10000 до 2000000000.
--ss задаёт сглаживание: 1, 2 или 3. При значении 2 расчёт идёт в удвоенном размере по каждой стороне, после чего изображение уменьшается.
--seed задаёт начальное число генератора случайных чисел.
--threads задаёт максимум потоков от 1 до 32. По умолчанию используется до четырёх.
--out задаёт путь к PNG.
--output-dir задаёт папку результата.
--all рассчитывает все шесть пресетов.
--no-open отключает открытие изображения после сохранения.
--list показывает список пресетов.
--help показывает справку.

Режимы качества

preview: 960 × 600, 2500000 итераций, сглаживание 1.
standard: 1600 × 1000, 18000000 итераций, сглаживание 2.
high: 2560 × 1600, 60000000 итераций, сглаживание 2.
ultra: 3840 × 2400, 160000000 итераций, сглаживание 2.

Примеры

./gradlew --quiet run --args="--preset galaxy --quality high"
./gradlew --quiet run --args="--preset phoenix --width 1920 --height 1080 --samples 40000000 --no-open"
./gradlew --quiet run --args="--all --quality preview --output-dir examples"
./gradlew --quiet run --args="--config configs/phoenix.properties --seed 123"

Свои конфиги

Проще всего скопировать один из готовых файлов из configs и изменить его. Файл должен быть в UTF-8.

id — короткое имя латиницей, которое используется в имени PNG.
name и description — название и описание.
seed — начальное число генератора.
symmetry — число поворотов точки вокруг начала координат, от 1 до 16.
rotation — поворот кадра в градусах.
zoom — масштаб. Значение больше 1 приближает изображение.
gamma — гамма-коррекция яркости.
exposure — настройка яркости по плотности точек.
vibrancy — степень сохранения цвета.
palette — цвета в формате #RRGGBB через запятую. Нужно минимум два цвета.
transforms — число преобразований.

Для каждого преобразования используются поля transform.0, transform.1 и так далее.

weight задаёт вероятность выбора преобразования. color задаёт положение цвета в палитре от 0 до 1. colorSpeed регулирует смешивание цвета текущей точки с цветом преобразования.

affine содержит шесть коэффициентов a,b,c,d,e,f. По ним вычисляются x'=a*x+b*y+c и y'=d*x+e*y+f. Необязательное поле post задаёт такое же преобразование после нелинейных функций.

variations содержит функции и их веса, например swirl:0.8,linear:0.2. Результаты функций умножаются на веса и складываются. Веса не нормализуются автоматически.

Доступные функции: linear, sinusoidal, spherical, swirl, horseshoe, polar, handkerchief, disc, julia, julian, bubble, eyefish и curl. У julia две ветви, у julian три. Параметры curl в этой версии фиксированные.

Повтор изображения

Нужно передать сохранённый рядом с PNG конфиг:
java -Xmx2g -jar build/libs/FlameStudio-1.0.0.jar --config renders/имя.properties --out renders/repeat.png --no-open

При одинаковой версии программы, Java, seed, числе потоков и настройках получаются одинаковые пиксели. Изменение числа потоков может немного изменить результат из-за порядка сложения дробных чисел. Новый seed меняет выборку точек, а для изменения самой формы нужно менять преобразования.

Как работает алгоритм

Сначала программа делает пробный проход, чтобы подобрать кадр. Затем несколько потоков выполняют chaos game. Для каждой точки выбирается преобразование с учётом его веса, применяются аффинное преобразование и нелинейные функции, смешивается цвет. Начальные итерации каждой цепочки пропускаются.

Положение и цвет точки записываются в буфер плотности. В конце буферы потоков объединяются. Для плотности применяется логарифмическая коррекция, после неё гамма-коррекция цвета, сглаживание разреженных областей и уменьшение изображения до нужного размера.

При подборе кадра используются центральные 99.8% пробных точек с запасом. Редкие выбросы могут не попасть в кадр. Если точка становится бесконечной или слишком далёкой, цепочка начинается заново.

Исходное описание метода: Scott Draves и Erik Reckase, The Fractal Flame Algorithm.
https://flam3.com/flame_draves.pdf

Устройство проекта

Main — меню, параметры запуска и сохранение файлов.
Preset — чтение конфигов, палитры и преобразований.
Variation — нелинейные математические функции.
FlameRenderer — расчёт точек, выбор кадра и обработка изображения.
RenderSettings — размеры, число итераций и готовые режимы качества.
RendererTests — интеграционные проверки.
configs — готовые пресеты.
gallery — примеры результатов.

Проверки

./gradlew check

Проверяются все пресеты, разные результаты, повторяемость seed, сохранение и чтение PNG, запрет перезаписи, прогресс расчёта, отмена и неверные настройки. Проверки также выполняются при build. Внешний тестовый фреймворк не используется.

Память

Большое изображение со сглаживанием требует много памяти. Программа уменьшает число потоков, если их буферы не помещаются в выделенную память. Если даже один буфер не помещается, нужно уменьшить размер или параметр --ss. Для запуска JAR с большим лимитом памяти можно заменить -Xmx2g на -Xmx4g.
